# Logo

Eine Waage, deren Säule das Zeichen des [Model Context Protocol](https://modelcontextprotocol.io) bildet: Gesetze für KI-Assistenten. Farbe ist Tintenblau `#1f4e79`.

| Datei | Wofür |
|---|---|
| [`logo.svg`](logo.svg) | Das Logo in Tintenblau, für helle Hintergründe. Im Seitenkopf von gesetze-fuer-ki.de. |
| [`logo-weiss.svg`](logo-weiss.svg) | Weiß, für dunkle oder tintenblaue Hintergründe. |
| [`logo-schatten.svg`](logo-schatten.svg) | Tintenblau mit weichem Schatten, für große Darstellungen wie das Org-Profil. |
| [`favicon.svg`](favicon.svg) | Mit dickeren Strichen, damit es bei 16 und 32 px lesbar bleibt. Favicon der Webseite. |
| [`avatar-hell.png`](avatar-hell.png) | 512 × 512 px, Tintenblau auf Weiß. Avatar für GitHub und Liberapay. |
| [`avatar-schatten.png`](avatar-schatten.png) | Wie `avatar-hell.png`, mit Schatten. |
| [`avatar-dunkel.png`](avatar-dunkel.png) | 512 × 512 px, Weiß auf Tintenblau. |

Die Dateien der Webseite liegen zusätzlich in [`gesetze-fuer-ki/docs`](https://github.com/Gesetze-fuer-KI/gesetze-fuer-ki/tree/main/docs); bei einer Änderung am Logo beide Stellen anpassen.
